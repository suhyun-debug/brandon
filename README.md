## 사이트

https://suhyun-debug.github.io/brandon/

## 배포

저장소 Settings → Pages → Source를 GitHub Actions로 설정합니다.
main 브랜치에 커밋이 반영되면 `.github/workflows/deploy-pages.yml`이 정적 파일을 배포합니다.
실패한 배포는 Actions에서 오류를 확인한 뒤 다시 실행할 수 있습니다.

## 데이터 연동

Google Sheets 및 Apps Script 연동 설정은 별도로 필요합니다. ERP 인증 정보와 토큰은 저장소에 커밋하지 말고 Apps Script 속성 등 비공개 설정에서 관리하세요.
